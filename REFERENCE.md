# The `.part` language, and the window's acts

Generated by `nacs --reference` from the parser's own key tables, the creation templates and the window's action table. Do not edit: regenerate (`nacs --reference > REFERENCE.md`); `tests/view_tests.rs` pins the file to the generator.

A project is a directory holding `main.part` (and, optionally, `geometry.part`). Lines are statements; `#` starts a comment; a block statement opens with `(` and closes with `)` on a later line, its points between.

## The header — one word, one value, each line

- `units <value>` — `mm` or `inch` — every number in the file is read in this unit
- `feed <value>` — the cutting feed, per minute
- `plunge <value>` — the descent feed, per minute
- `spindle <value>` — rpm
- `rapid_z <value>` — the height every entry rapids to before feeding — above the stock top
- `clearance_z <value>` — the between-operations retract — above the stock top
- `work_offset <register>...` — optional: the register the program selects, `G54` to `G59` (`G54` unwritten); several run the program at each, one part a register

## The stock — the blank, declared first

- `stock Box(w=, l=, h=, x=, y=, z=, material=)` — `w`, `l`, `h` required; `x`, `y` the datum corner, `z` the TOP (0 when absent)
- `stock Cylinder(dia=, h=, x=, y=, z=, material=)` — `dia`, `h` required; `x`, `y` the axis, `z` the top
- `stock Profile(h=, z=, material=)` + `x y` point lines + `)` — a blank whose plan outline is the loop (CCW); `h` required, `z` the top

## Tools — `tool T<n> <Kind>(key=value, …)`

- **Endmill** — `dia`, `flute_len`?, `shank_dia`?, `neck_dia`?, `neck_len`?, `stickout`?, `flute_count`?, `holder`?, `holder_nose_dia`?, `holder_nose_len`?, `holder_body_dia`?, `coolant`?
- **Ballmill** — `dia`, `flute_len`?, `shank_dia`?, `neck_dia`?, `neck_len`?, `stickout`?, `flute_count`?, `holder`?, `holder_nose_dia`?, `holder_nose_len`?, `holder_body_dia`?, `coolant`?
- **Drill** — `dia`, `flute_len`?, `shank_dia`?, `neck_dia`?, `neck_len`?, `stickout`?, `flute_count`?, `holder`?, `holder_nose_dia`?, `holder_nose_len`?, `holder_body_dia`?, `coolant`?
- **FormTool** — `dia`, `profile`, `cut_bottom`?, `cut_top`?, `source`?, `flute_len`?, `shank_dia`?, `neck_dia`?, `neck_len`?, `stickout`?, `flute_count`?, `holder`?, `holder_nose_dia`?, `holder_nose_len`?, `holder_body_dia`?, `coolant`?
- **CornerRounder** — `radius`, `effective_dia`, `gauge_z`, `dia`, `pilot`, `radius_error`?, `trail_wall`?, `trail_face`?, `source`?, `flute_len`?, `shank_dia`?, `neck_dia`?, `neck_len`?, `stickout`?, `flute_count`?, `holder`?, `holder_nose_dia`?, `holder_nose_len`?, `holder_body_dia`?, `coolant`?
  - `radius`: the arc's radius, as sold
  - `effective_dia`: the diameter the arc meets the wall at
  - `gauge_z`: height above the tip of the arc's top; not the tool's length
  - `dia`: the body's outside diameter, above the arc
  - `pilot`: the diameter of the end below the arc
- **ChamferMill** — `angle`, `gauge_dia`, `gauge_z`, `dia`, `tip_dia`, `angle_error`?, `source`?, `flute_len`?, `shank_dia`?, `neck_dia`?, `neck_len`?, `stickout`?, `flute_count`?, `holder`?, `holder_nose_dia`?, `holder_nose_len`?, `holder_body_dia`?, `coolant`?
  - `angle`: the included angle of the cone, as sold: 90 cuts a 45° chamfer
  - `gauge_dia`: a diameter measured on the cone
  - `gauge_z`: height above the tip of gauge_dia; not the tool's length
  - `dia`: the body's outside diameter, above the cone
  - `tip_dia`: the flat at the tip; no ground cone comes to a point

(`?` marks an optional key; the body keys at the end of every kind describe the shank and holder for the collision checks.)

- **ProfilePocket** — `z`?, `extent`, `edge_round`?, `chamfer_depth`?, `chamfer_width`?, `chamfer_angle`? — then the points, `x y` per line, a planar loop (a pocket CCW, a boss CW); a point may add `chamfer_depth=` or `chamfer_width=` to restate the leg for the edges from it on, 0 for none; beside `edge_round` the points alone give a leg, bevelling those edges where the rest are rounded

## Operations — `run <Verb>(tool=T<n>, <reference>=<feature>, key=value, …)`

The verbs name the part of the tool that cuts: **End** (the end — a face or a floor), **Side** (the flank — a wall or an outside profile), **Clear** (a volume — the pocket's material), **Copy** (the surface — a 3D finish), **Form** (a form tool or a drill; with `points=[…]`, a visit to holes). Each reads one reference: `surface=` for End, Side, Copy and Form, `profile=` for Clear, `points=[…]` for a Form or an End at points.

The keys a `run` line takes:

- `tool=`
- `surface=`
- `profile=`
- `points=`
- `cycle=` — one of `Simple`, `Peck`
- `peck_increment=` (mm)
- `stepover=` (mm)
- `stepdown=` (mm)
- `scallop=` (mm)
- `feed=` (mm/min)
- `plunge=` (mm/min)
- `rapid_z=` (mm)
- `clearance_z=` (mm)
- `spindle=` (rpm)
- `comp=` — one of `engine`, `control`
- `compress=` — one of `chords`, `arcs`
- `stock_to_leave=` (mm)
- `wall_standoff=` (mm)
- `face_standoff=` (mm)
- `tip_clearance=` (mm)
- `strategy=` — one of `rest`, `regions`
- `voxel_cell=` (mm)
- `coolant=` — one of `flood`, `mist`, `air`, `through`, `off`, `custom1`, `custom2`, `custom3`
- `n=`
- `pattern=` — one of `offset`, `zigzag`, `oneway`, `spine`, `held`
- `engagement=` (°)
- `cover=`
- `direction=` — one of `climb`, `conventional`
- `angle=` (°)
- `entry=` — one of `ramp`, `plunge`, `lead`
- `lead=` (mm)
- `lead_angle=` (°)
- `lead_descent=` (°)

**Window ▸ Theme** — the built-in palette, then the themes carried in the binary, then any `<name>.json` in the config folder (`%APPDATA%\nacs\themes` on Windows, `~/.config/nacs/themes` elsewhere; a file there wins by name). A pick is `--theme <name>`'s twin and is remembered in the workspace file; a change of `background.appearance` takes effect at the next launch.
**Window ▸ Switch window frame** — the window wears its own frame by default (Phase 57): the band is the title bar — drag it to move the window, double-click it to maximize or restore — with the caption buttons at its right end; on Windows 11 the corners are rounded and the border takes the theme's `border` colour. The switch puts the system's frame back, live, and is remembered as `frame native` in the workspace file; `--frame native` with `--view` is the switch's twin and is remembered the same way, as a `--theme` pick is.
**Output's line** — Enter runs the line in the project's directory, its words into the log above with the exit said last, one run at a time: `nacs <flags>` (this binary on this project; a line that starts with a flag is read as nacs's), `import <file.step> [up=…] [solid=N] [allowance=…] [origin=…] [given=…]` and `stock <file.step> [up=…] [solid=N] [allowance=…] [given=…]` (the sidecar; `given=` names the program before this one, whose blank turned over is the proposed stock), `git <verb>` (status, log, diff, show, branch, remote, fetch, pull, push, commit -m …, switch), and `sh <line>` — everything after `sh`, as typed, handed whole to the shell: the system's (`COMSPEC` on Windows, `/bin/sh` elsewhere) unless `shell <program>` in the workspace file names another, run as `<program> -c <line>`; the log says which under the echo. Anything else is refused by name and nothing runs. ↑ and ↓ on the line walk what was entered since the window opened, newest first — a refused line too, so a typo comes back to fix — and past the newest the line being typed comes back; the window's own memory, written to no file.
